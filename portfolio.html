Invasion

Hand-builtTurret defense game in Java (Greenfoot), June 2025

A top-down survival game written in Java with Greenfoot for my final project. Slimes crawl in from every edge of the map and chase you down. Every slime your defenses destroy earns $1, and you spend it on more defenses before the horde wears through your five hearts.

Building happens mid-fight on single keys: walls (C) start at $10 and cost $10 more with each one you place, turrets (X) cost $50 and land mines (Z) cost $10. The longer you survive the faster slimes spawn, and your score is how many seconds you lasted.

  • Java
  • Greenfoot
  • Object-oriented design

How it works

  1. Every frame rolls a random number to decide whether a slime spawns. The roll's range shrinks each second, so spawns go from occasional to constant
  2. Up to four turrets fire on their own timers at 1, 2 or 3 shots a second. Two lock onto the oldest slime on the map and two onto the newest, and the fourth fires explosive rounds
  3. Turrets turn toward their target with atan2 on a small Vector class I wrote, and bullets fly along that heading
  4. Walls soak up five slimes before crumbling, and mines blow up the moment a slime steps on one

PyTag Online

Hand-builtTwo-player online tag over Python sockets, 2025
View code

A two-player online game of tag written in Python with pygame for Computer Science 1. Two players connect to a server, one is randomly made the tagger, and the runner has to survive 100 seconds in an arena full of obstacles.

There is no game engine or networking library underneath it: just raw TCP sockets, threads and the game's own player objects sent back and forth every frame.

  • Python
  • pygame
  • socket
  • threading
  • pickle

How it works

  1. A threaded TCP server accepts two clients and randomly picks which one is the tagger
  2. Every frame (25 fps) each client pickles its Player object, sends it to the server and gets the opponent's state back
  3. Pixel-mask collision decides a tag: the tagger has to be mid-dash when the sprites overlap
  4. The runner wins by surviving 100 seconds. Dash (J/Z) and roll (K/X) run on cooldowns

Controls: WASD or arrow keys to move, J or Z to dash, K or X to roll. Built for Computer Science 1, 2024-2025.

Handwritten Digit Classifier

Hand-builtk-nearest neighbors on MNIST, January 2026
View code

A k-nearest-neighbors classifier for handwritten digits. It loads the 60,000 training and 10,000 test images of MNIST from JSON, flattens each 28 by 28 image into a 784-number vector and trains OpenCV's KNearest model on them.

To classify a digit it finds the k training images closest to it and takes a vote. The script then plots test digits with their true label and the model's prediction so you can see exactly where it gets fooled.

  • Python
  • OpenCV (cv2.ml)
  • NumPy
  • Matplotlib
  • scikit-learn
  • tqdm

The Box

Hand-builtGame Lab arcade game in JavaScript (Code.org)
Play it

A ten-level puzzle platformer written in JavaScript in Code.org Game Lab. Every level traps a stick figure inside a walled box, and the whole game is finding the way out: a gap in a wall, a hidden opening, or a door that needs a key.

LHRIC Intern Time Card

AI-assistedBuilt for interns at Southern Westchester BOCES, 2026
Open Time Card

Interns at the Lower Hudson Regional Information Center log hours on an official paper timecard. This app replaces the paperwork: sign in with Google, fill in each day's time in, lunch and time out, and the totals calculate as you type.

Export stamps every entry, the weekly total and an optional drawn signature onto a copy of the official LHRIC timecard PDF and downloads it, ready to hand in.

  • JavaScript
  • Firebase Auth
  • Cloud Firestore
  • pdf-lib
  • Canvas

How it works

  1. Each intern's week lives in their own Firestore document, cached offline so it syncs across devices
  2. A stopwatch button stamps the current time. Entering one date fills in the rest of the week
  3. pdf-lib writes every field onto the real form at calibrated coordinates
  4. Past weeks are archived and can be re-exported. JSON backup and restore is built in

Ask Me Anything

AI-assistedEmail-to-AI bridge for use during school

I connected the ChatGPT API to Google Cloud so that from any computer I could email a specific account with a specific subject line. The program picks the message up, runs it through ChatGPT and replies with the answer within about 30 seconds.

It let me use AI during school hours from any computer with email, for learning only and never for plagiarism.

  • Google Cloud
  • Gmail
  • ChatGPT API

How it works

  1. Send an email to the dedicated inbox with the trigger subject
  2. A program on Google Cloud checks for new messages that match
  3. The message body is sent to the ChatGPT API
  4. The answer is emailed back to the sender
